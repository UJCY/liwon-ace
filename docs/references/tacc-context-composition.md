# 필수 참조 [1] — MCP 컨텍스트 구성이 소형 언어모델 성능에 미치는 영향

> 전현우(Codepedia Labs), 김태성(Liwonace Corp.), 강현(세종대) (2026-03).
> "The Effect of MCP Context Composition on Small Language Model Performance: A Model-Dependent Marginal Utility Analysis"
> https://zenodo.org/records/18842478 · 과제가 말하는 **TACC(선택적 컨텍스트 큐레이션)의 원 출처**.

## 한 줄 요약

소형 LLM에게 MCP 컨텍스트는 "많이 줄수록 좋다"가 아니다 — 어떤 컴포넌트가 유익한지는 **모델 능력**과 **과업 유형**에 따라 다르므로, 선별적으로 구성해야 한다.

## 실험 설계

- **모델 2종**: Qwen 2.5 7B (Q4_K_M, 한국어 파인튜닝) / Llama 3.1 8B (Q4_K_M, 한국어 제한적). 둘 다 Ollama, CPU 전용, 컨텍스트 4,096 토큰, temperature 0.1.
- **컨텍스트 4요소를 2⁴=16 조합으로 요인 실험**:

| 요소 | 기호 | 내용 | 평균 토큰 |
|------|------|------|----------|
| Knowledge Base | K | 벡터 DB에서 가져온 도메인 지식 | ~58 |
| Actions | A | 실행 가능한 MCP 도구 설명 | ~45 |
| Diagnostics | D | 실시간 메트릭·로그·상태 | ~235 |
| Guidelines | G | 운영 절차 | ~19 |

- 인프라 운영 10개 시나리오(모니터링·오류분석·운영결정·연쇄분석·코드수리), 총 **3,805회 실행** (핵심 비교는 n=15).

## 확정된 결과 (통계적으로 유의)

1. **컨텍스트는 반드시 줘야 한다**: 풀 컨텍스트가 빈 컨텍스트를 양 모델 모두 크게 이김 (Qwen d=0.835, Llama d=0.501, 둘 다 p<0.001).
2. **주효과가 유의한 건 K뿐** (Δ=+0.119, p=0.028). A는 경계선(p=0.114), D·G는 비유의. → 7B급에서 가장 중요한 건 도메인 지식.
3. **추가 컨텍스트(D·G)의 한계효용은 모델 의존적**: Qwen은 풀 컨텍스트가 K+A보다 유의하게 좋음(p<0.001), Llama는 차이 없음(p=0.210). 한국어 능력이 약한 Llama에게 D·G는 신호가 아니라 노이즈.
4. **과업 유형이 분산의 ~56%를 설명** (ICC≈0.56 양 모델): 최적 컨텍스트 구성은 과업 유형별로 달라진다.
5. **토큰 효율**: K+A는 토큰 +11%로 점수 +38% (Qwen). D+G는 +30% 토큰에 +0.075점 — 모델에 따라 비용 대비 무가치.

## 탐색적 결과 (검증 안 됨 — 가설 수준)

- 일부 시나리오에서 K+A가 풀 컨텍스트를 이기는 "컨텍스트 과부하" 관찰 (Qwen 3/10, Llama 1/10, raw p<0.05) — Bonferroni 교정 후 생존한 케이스 없음.
- **TACC 매트릭스** (과업 유형 → 권장 컨텍스트): 인프라 모니터링 K+D, 오류 분석 A+D+G, 운영 결정 K만, 연쇄 분석 K+G, 코드 수리 전부. **전향적 검증 없는 가설 생성용** — 논문 스스로 명시.

## 한계 (논문 명시)

모델 2종뿐(Gemma 미검증), 시나리오·채점 자체 설계, TACC 매트릭스 미검증, n=5 시나리오별 검정력 부족.

## 우리 설계에 주는 시사점

| 논문 발견 | 우리 설계 연결 |
|----------|--------------|
| K(도메인 지식)만 유의 | `ask` 반환 컨텍스트의 우선순위: 검색된 데이터(K 성격)를 최우선, 부가 진단·절차 텍스트는 자제 |
| 과업 유형이 분산 56% 설명 | **규칙 라우터가 TACC의 자연스러운 적용 지점** — 라우터는 질문 유형을 이미 판별하므로, 유형별로 반환 컨텍스트 구성을 다르게 갈 수 있음 (design.md 열린 항목 "TACC 적용 세부"의 방향) |
| 한계효용은 모델 의존 | 권장 LLM(Gemma 4 E2B)은 논문 미검증 모델 — 컨텍스트 구성을 상수로 박지 말고 조정 가능하게 설계, 자체 실험으로 확인 |
| 컨텍스트 과부하 | D2 개별 도구 노출 시에도 도구 결과를 그대로 다 넘기지 않기 — Q2(컨텍스트 초과) 케이스와 일치 |
| 언어 능력이 D·G 활용 좌우 | 데이터셋·질문이 한국어 — 선택 모델의 한국어 능력 확인이 선행 조건 |

**주의**: TACC 매트릭스 자체는 탐색적 가설이다. 과제 요구("TACC 적용")는 매트릭스를 그대로 베끼라는 게 아니라 "선별 구성" 원칙의 적용으로 해석하는 것이 안전 — 우리 데이터·모델로 간단히 재검증하고 적용하는 편이 심사 어필도 큼.
